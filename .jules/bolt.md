## 2026-05-20 - [Winston Logging Formatter Overhead]
**Learning:** Performance measurements demonstrate that passing structured objects to the Winston logger is ~1.2x faster than passing and parsing JSON strings within the `printf` formatter. When passing an object directly to Winston (e.g., `logger.http(httpLog)`), Winston merges the object's properties into the top-level `info` object instead of nesting them under `info.message`.
**Action:** When creating custom log formatters for Winston, design them to read extracted top-level properties from the `info` object directly instead of relying on `JSON.parse` inside the formatter logic.
